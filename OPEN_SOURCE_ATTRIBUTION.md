# OPEN-SOURCE ATTRIBUTION & ACKNOWLEDGEMENTS
## Architectural Inspirations and Standards

AidGrid studies and respects existing civic technology platforms and open standards.

---

### 1. Architectural Inspirations

1. **Open311 GeoReport v2 Standard**
   - Standard reference: Open311 GeoReport API specification
   - Implementation: AidGrid provides `/api/open311/v2/services` and `/api/open311/v2/requests` adapter endpoints compatible with civic reporting schemas.

2. **FixMyStreet (mySociety)**
   - Reference: https://github.com/mysociety/fixmystreet
   - Conceptual influence: Public map-based issue exploration, category-based routing, and transparent status histories.

3. **Ushahidi Platform**
   - Reference: https://github.com/ushahidi/platform
   - Conceptual influence: Community corroboration and multi-source civic problem validation.
